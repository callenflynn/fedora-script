# Fedora Script

A simple Fedora desktop setup script.

## Install

Clone the repo, then run:

```bash
git clone https://github.com/callenflynn/fedora-script.git
cd fedora-script
chmod +x setup.sh
./setup.sh
```

Choose **GNOME** or **KDE Plasma** when asked.

The script installs the apps, LazyVim, McMojave cursors, dark mode, and the wallpapers in `bg/`.

Run it as your normal user. `sudo` is required.
